# 🎓 Student Performance Tracker

A web-based Student Performance Tracker developed using **Python** and **Streamlit**.

## 📌 Features

- Add Student Details
- Calculate Total Marks
- Calculate Average
- Generate Grade Automatically
- View Student Records
- Search Student by ID
- Delete Student Record
- Download Student Report as CSV

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

2. Move to the project folder

```bash
cd YOUR_REPOSITORY
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```

## 🌐 Deployment

This project is deployed using **Streamlit Community Cloud**.

## 📖 Project Description

The Student Performance Tracker is a simple web application that helps manage student academic records. Users can add student details, calculate total marks, average scores, and grades, search and delete records, and download the data as a CSV report.
